# PortFlow 360 — Port Cargo Handling Company

Academic prototype for the ITBT Live Class Exercise.

## Business problem
Port managers need immediate visibility of vessel arrivals, containers, cargo throughput, pending movements and turnaround. PortFlow 360 provides a simple operations control tower.

## Main features
- Home, About, Services, Dashboard and Contact
- 6 management KPIs
- Daily cargo throughput chart
- Vessel schedule
- Interactive container tracking
- Pending-container watchlist
- Enquiry form
- Business-purpose hyperlinks
- Responsive design
- GitHub Pages ready

## Deployment
Upload all files and the `images` folder to a public GitHub repository. Then use Settings → Pages → Deploy from a branch → main → / (root).

## Note
All numbers, prices and records are illustrative academic demo data. This prototype is not connected to a live port terminal operating system, TOS, customs system or database.
